# 原生工作台 UI 验收

2026-11-19。基于外部 agent 已实现的 SwiftUI 工作台继续检查并修复，视觉基准为 [第二版设计稿](../workbench-native.html)。本页截图来自真实 Release 可执行程序的隔离演示模式。

## 本轮修复

| 问题 | 调整 |
| --- | --- |
| 标题栏同时出现页面名与应用名 | 使用系统统一工具栏并隐藏重复的窗口标题 |
| 助理主区发灰，配置菜单横向拉伸 | 主内容使用系统内容背景，菜单按标签实际宽度排列，强调色集中在发送动作 |
| 任务列表、检查器过宽 | 限制分栏宽度，保留主工作内容；任务页直接使用列表与详情，避免额外检查器造成四栏挤压 |
| 列表时间过长、选中态对比不足 | 使用紧凑时间并保留完整时间提示；区分焦点内的强调选中与失焦后的普通选中 |
| 检查器内容挤在分隔线上 | 增加分组底部间距，简化重复说明与时间展示 |
| 验收窗口在最小窗口中过高 | 调整为 660×600，补充所验任务名称，持续保留底部操作与说明输入 |
| 待我处理漏掉待验收任务 | 增加待验收区和 Sheet 入口，侧栏与工具栏同步统计待回答、待验收事项 |
| 辅助页面仍存在大标题、过宽表单与卡片 | 电脑、记忆、定时关注、成本统一为紧凑标题与系统按钮，约束内容与表单宽度 |
| 电脑页默认设置已选值过浅 | 使用带明确前景文字的原生菜单，保留原有引擎、默认电脑与主助理电脑的绑定和保存逻辑 |

保留原有 API、任务操作、父子归属与前置依赖、证据校验和认证链路。本轮修改叠加在已有未提交实现上，没有回退其他 agent 的工作。
