# 记忆页面设计稿

2026-11-19。延续已认可的 Mac 原生工作台方向，已接入 [workbench-native.html 的记忆页](workbench-native.html#memories)。这是 HTML 交互提案，本轮没有修改 Swift 客户端或服务端。

## 布局与视觉

沿用主工作台的系统字体、中性灰背景和紫色操作强调。结构为主侧栏、可调宽的记忆列表、常驻内容详情。列表默认宽 300 px，较小窗口适当收紧；详情以文档阅读为主，不把完整记忆排列成等权卡片。

工具栏显示“记忆”和已加载/待审核数量，新建动作对应当前记忆页。连接状态固定在列表底部，地址、令牌和导入入口放进独立 Sheet。

列表使用“全部 / 已验证 / 待审核 / 需关注”四项筛选，类型另用紧凑菜单。条目呈现标题、短摘要、状态和更新时间。详情显示完整内容、类型、状态、版本，并提供“内容 / 来源与范围”切换。

## 已演示的交互

- 对已加载记忆按标题、内容、项目、站点、标签进行本地搜索，组合状态与类型筛选。
- 点击或上下方向键选择条目，详情就地更新；记忆列表可调宽。
- 新建记忆使用 Sheet；编辑现有内容留在详情中，切换条目时保留未保存草稿。
- 候选可先修正并“保存待审核”，核对内容和范围后再“审核并发布”。本稿的核对勾选属于客户端交互提案，不代表新增服务端接口规则。
- 审核不会把模型推断改写成事实；已审核的推断继续使用琥珀色“已审核（推断）”和明确提示。
- 删除使用确认窗口，不虚构回收站、撤销或历史还原能力。
- 连接设置不回显已有令牌；示例地址使用 `memory.example`。保存不发请求，配置导入只预览文件名，不读取文件内容。
- 覆盖未连接、搜索无结果、没有待审核内容三类空态。

快捷键：⌘K / ⌘F 聚焦当前记忆搜索，⌘N 在记忆页打开新建；原有任务页、助理页和其他导航继续保留。浏览器可能优先处理自身保留快捷键，原生落地使用 SwiftUI Commands。

## 状态与实现边界

设计以当前 Memory / MemoryGovernance 字段为依据：类型、版本、来源类别、创建和更新时间、项目、站点、标签、有效期、使用次数，以及治理状态与内容性质。

- 候选尚待审核；冲突、过期、待更新、已被替代分别表达，不能用普通已验证绿色覆盖。
- “已加载 N 条”仅描述当前页面的数据，不表示整个 Recall 库总量。
- 来源说明为示例可读摘要；未根据 `sessionId` 伪造来源任务链接。
- 项目、范围、标签和治理信息在本稿中只读。实际能否用于任务，由任务授权与当前记忆治理规则决定。
- 已发布内容与版本的权威仍是 Recall。设计稿只模拟版本元信息与本页状态，不新增历史浏览/还原、冲突自动解决或有效期修改接口。

Swift 落地可对应原生 List 的选择绑定、HSplitView、分段 Picker、TextEditor、Sheet 与 Menu；HTML 中的窗口装饰和控件仅用于评审布局。
